# ساخت خودکار APK در گیت‌هاب

<div dir="rtl">

## نحوه کار

این پروژه به‌گونه‌ای پیکربندی شده که به‌صورت **خودکار** در گیت‌هاب APK می‌سازد. لازم نیست Android Studio یا JDK روی سیستم شما نصب باشد!

## مراحل دریافت APK

### روش ۱: از طریق Actions (همیشه موجود)

۱. به آدرس ریپازیتوری بروید:
   ```
   https://github.com/aria0939/moghayerat-gir/actions
   ```

۲. روی جدیدترین run (معمولاً سبز رنگ ✓) کلیک کنید

۳. در پایین صفحه، در بخش **Artifacts**، دو فایل می‌بینید:
   - `moghayerat-gir-debug` (نسخه دیباگ، سریع برای تست)
   - `moghayerat-gir-release` (نسخه نهایی)

۴. روی هر کدام کلیک کنید تا فایل ZIP دانلود شود

۵. فایل ZIP را استخراج کنید - فایل APK داخل آن است

### روش ۲: از طریق Releases (نسخه‌های نهایی)

۱. به آدرس زیر بروید:
   ```
   https://github.com/aria0939/moghayerat-gir/releases
   ```

۲. آخرین release را پیدا کنید

۳. در بخش **Assets**، فایل APK را دانلود کنید

**نکته**: Releases فقط زمانی ساخته می‌شوند که یک tag با فرمت `v1.0.0` ایجاد کنید. در غیر این صورت، از روش ۱ استفاده کنید.

## نصب APK روی گوشی

۱. فایل APK را روی گوشی اندرویدی (نسخه ۸.۰ به بالا) کپی کنید
۲. در تنظیمات گوشی → Security → "نصب از منابع ناشناخته" را فعال کنید
۳. با File Manager به فایل APK بروید و روی آن کلیک کنید
۴. روی Install کلیک کنید

## ساخت مجدد APK

هر زمان که تغییراتی در کد دادید و آن را push کردید، گیت‌هاب به‌صورت خودکار APK جدید می‌سازد. می‌توانید به‌صورت دستی هم build را اجرا کنید:

۱. به تب Actions بروید
۲. در سمت چپ، روی "Build and Release APK" کلیک کنید
۳. روی دکمه "Run workflow" کلیک کنید
۴. منتظر بمانید تا build کامل شود (حدود ۵-۱۰ دقیقه)

## ساخت Release با tag

اگر می‌خواهید یک نسخه نهایی با tag ایجاد کنید:

```bash
git tag v1.0.0
git push origin v1.0.0
```

این کار به‌صورت خودکار یک release می‌سازد و APK را در بخش Releases قرار می‌دهد.

## عیب‌یابی

### مشکل: Build failed

اگر build در گیت‌هاب ناموفق بود:

۱. به تب Actions بروید و روی run ناموفق کلیک کنید
۲. خطا را در لاگ‌ها پیدا کنید
۳. در صورت نیاز، issue در گیت‌هاب باز کنید

### مشکل: APK نصب نمی‌شود

- مطمئن شوید گوشی حداقل Android 8.0 دارد
- فضای کافی روی گوشی داشته باشید (حداقل ۵۰ مگابایت)
- "نصب از منابع ناشناخته" را فعال کنید

## اطلاعات فنی

- **CI/CD**: GitHub Actions
- **Runner**: ubuntu-latest
- **JDK**: Temurin 17
- **Android SDK**: API 34
- **Gradle**: 8.5
- **Build time**: حدود ۵-۱۰ دقیقه
